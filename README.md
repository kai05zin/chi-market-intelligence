# CHI Market Intelligence

## Project Overview

CHI Market Intelligence is an end-to-end analytics project designed to identify
high-potential Chicago neighborhoods for restaurant expansion.

## Business Question

Which Chicago neighborhoods offer the strongest opportunities for opening
a new restaurant based on market size, competition, accessibility, and local conditions?
